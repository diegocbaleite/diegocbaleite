### 🐾 Sistema de Adoção de Animais

API REST desenvolvida com **Java 21 e Spring Boot** para gerenciamento de usuários, animais, abrigos e processos de adoção.

**Tecnologias:**

`Java 21` • `Spring Boot` • `Spring Data JPA` • `PostgreSQL` • `MinIO` • `Swagger/OpenAPI`

Principais conceitos aplicados:

* Arquitetura em camadas
* DTOs e Mappers
* Bean Validation
* Tratamento global de exceções
* Relacionamentos JPA
* Upload e armazenamento de imagens
* Documentação de API com Swagger/OpenAPI
